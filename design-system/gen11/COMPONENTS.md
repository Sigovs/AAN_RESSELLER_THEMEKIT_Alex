# Gen 11 — COMPONENTS

The index of what the catalogue shows. Every row is a specimen rendered in
`index.html` from the product's own DOM and the product's own stylesheets.

Generated by `_tools/gen-components.js` from the same extraction that builds
the specimen hosts, so this document and the catalogue cannot disagree.

**120 specimens** in **32 groups** across **10 chapters**.

Geometry is measured at 1440×900. CONTEXT is the ancestor chain the component's
CSS is scoped to — a leaf lifted out of it renders unstyled.

## Reading a specimen

Under every specimen in the catalogue:

    SELECTOR   the element itself, with its classes
    CONTEXT    the ancestor chain its CSS is scoped to
    SOURCE     every stylesheet that contributes a rule
    USED ON    the page it was taken from
    MEASURED   box, padding, gap, radius at 1440×900

If a component you need is not here, check `PAGE-SPECIFIC.md` — 205 families
occur on exactly one page and are recorded there rather than promoted into a
shared abstraction that does not exist.
