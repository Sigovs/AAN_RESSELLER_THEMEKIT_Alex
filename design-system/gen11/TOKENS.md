# Gen 11 — TOKENS

The values the ten shipped pages actually compute, read out of the running
product rather than out of a spec. Generated by `_tools/gen-tokens.js`.

| | |
|---|---|
| distinct custom properties | **193** |
| same value on every page that declares them | **188** |
| genuinely differ between pages | **5** |

A token layer that agrees with itself on 97% of its surface is the reason the family
reads as one product. The five disagreements below are real and are kept.

## Where the pages disagree

| token | value | pages |
|---|---|---|
| `--anchor-gap` | `10px` | all-vehicles, single-vehicle, accounting, single-lead, all-leads |
|  | `12px` | single-ticket |
| `--dock` | `440px` | all-vehicles, all-leads |
|  | `400px` | single-ticket, single-lead |
| `--mono` | `"Plex Mono", ui-monospace, monospace` | all-vehicles, single-vehicle, my-work-queue, single-ticket, manage-dealers, dealer-edit, accounting, single-lead, all-leads |
|  | `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` | dealer-login |
| `--row` | `74px` | all-vehicles, single-lead, all-leads |
|  | `64px` | my-work-queue |
|  | `56px` | manage-dealers |
|  | `52px` | accounting |
| `--stick-total` | `calc(56px + 56px + 40px)` | all-vehicles, single-lead, all-leads |
|  | `calc(56px + 72px)` | single-vehicle |

`--row` is table density and is meant to differ: an inventory row carries a
thumbnail, a work-queue row carries seventeen columns of text. `--dock` is the
width of a contextual panel and follows what the panel holds. `--stick-total`
is derived from the sticky layers a page actually has, which is why it must
never be hardcoded. `--anchor-gap` and the mono fallback list are the two that
could be unified and have not been.

## How to use them

Take the tokens from `dist/aan-gen11.css`, which carries the shared layer. The
page-level tokens above (`--row`, `--cols`, `--dock`) belong to the page: a new
page declares its own, on the ladder, and does not borrow another page's value
because it happens to be nearby.

The ladder is `4 · 8 · 12 · 16 · 24 · 32 · 40 · 48 · 64`. A value off the ladder
is a decision that has to be defensible in a comment, not a rounding error.
