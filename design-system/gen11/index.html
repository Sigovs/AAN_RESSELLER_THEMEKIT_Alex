View · filter · section

three different questions, three treatments
View track.ui-views / .ui-view

Answers which view am I in. No well under it — twelve lanes in a sunken track produced a 1250px grey bar, the heaviest object on a page whose subject is the list below. Only the current lane is an object.

Filter set.ui-filters / .ui-filter

Answers which records are visible. Chips on the ground with a caps key, so it never reads as a second view track.

Buttons

one primary per group, 8px apart, never touching
On the dark surface

A primary on a dark bar keeps light ink, including when disabled. A generic light hover must never reach a dark surface — it once turned the one dark card on a page into a pale slab at 1.2:1.

Status chips

the only legitimate pill

Pills are for status and true capsules. Not toolbar buttons, navigation, filters, titles or actions — those take 7px or 9px.

Table

one header voice, four densities

Header labels are centred, 11/700 caps. A sortable cell is a control that inherits the header's voice — otherwise a header row reads half caps, half sentence case. Row height is the density dial: 74 media · 64 operational · 56 register · 52 ledger.
