One system, from tokens to pages

Every component of the AAN control panel, in the order it is built: tokens make atoms, atoms make molecules, molecules make organisms, organisms make page templates, templates become pages. Each card shows the Gen 11 reference as drawn on its origin page, next to the same component on the new backend's own ui-* markup with the two package layers applied. If the two sides differ, the package is wrong, not the page.

Pattern added from the test page: record with sub-lines

Feeds Incoming

When one record owns several lines (a dealer with several feeds), the record's identity and its record-level actions span all its lines; each line carries its own cells and actions; a hairline separates the lines inside the record, a stronger line separates records. No nested tables, no expanders.
