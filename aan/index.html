What changed

Twelve things, in the order they were fixed

Each was measured before and after in a real browser at 1280 / 1366 / 1440 / 1920. The numbers live in the stage reports at the repository root.

  • Foundation cleaned. 1 021 CSS rules collapsed to 747; twelve competing :root blocks became one. Dead rules removed, component definitions consolidated, nth-child selectors replaced by semantic classes.
  • 1366 overflow corrected. Horizontal overflow is now 0 at every tested width, in the default, filters-open and vehicle-open states.
  • Sticky mechanics stabilised. CSS publishes the stack geometry and JS reads it. The engaged state could previously never fire — the script carried thresholds from a layout two versions old.
  • Layer collisions corrected. A named z-index ladder; content travels under chrome, so hiding the column header is no longer necessary.
  • Focus treatment corrected. Focus owns outline alone. It used to ride on box-shadow, which every decorative shadow overwrote.
  • Dark mode safely gated. Off behind one flag, its rules inert rather than half-applied.
  • Selected-row anchor. Opening a vehicle brings its row to rest 202px under the sticky stack — measured deviation −0.67px to 0, in both travel directions, under reduced motion, and with the dock open. Near the end of the list the document extends so the last row can still reach it.
  • In-flow vehicle workspace. The detail was an absolutely-positioned card that floated over as many as fourteen rows while the other fifteen were dimmed. It is now part of the list: 0 rows covered, 0 dimmed, 0 seam, edges identical to the row's.
  • Detail as a stacked accordion. Four regions down one column at full width, each opening in place and pushing the ones below it. No 2×2 grid, no column teleporting, no tabs, no rail.
  • Market + Comps unified. They were always reporting the same number of listings. One region now, with the not connected disclosure above the price distribution rather than buried under it.
  • Sticky visual system completed. Platform bar, command band and column header are one attached surface: square touching corners, one inset, one hairline per boundary, one shadow at the bottom edge. The translucent holes at the seams are gone.
  • 8pt spacing system. One ladder — 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 — with named structural tokens. The same relationship always takes the same token.
Notes. All pages are static prototypes on demo data; names, phones and emails are simulated; buttons, filters and menus demonstrate states, not a backend. Facet counts, market figures, comparable listings and history are illustrative and marked Demo — no market source is connected.
